# 🤖 Bot Telegram 24/7

O bot agora funciona automaticamente 24 horas por dia! 🚀

## Como funciona

O bot usa **Vercel Serverless Functions** que ficam disponíveis 24/7 automaticamente.

## Comandos disponíveis

| Comando | O que faz |
|---------|-----------|
| `/start` | Responde com seu Chat ID |
| `/hoje` | Mostra agendamentos do dia de hoje |
| `/agenda` | Mostra agendamentos do dia de hoje |
| `oi` | Responde com seu Chat ID |

## Configuração inicial

### 1. Fazer deploy

```bash
cd ~/temp/pereira-barbershop
git add api/telegram.js
git commit -m "feat: adicionar bot telegram 24/7"
git push origin main
```

O Vercel vai fazer deploy automático.

### 2. Configurar webhook

Após o deploy estar pronto (cerca de 1-2 minutos), rode:

```bash
cd ~/temp/pereira-barbershop
bash scripts/configurar_webhook.sh
```

Isso configura o Telegram para enviar mensagens para o Vercel automaticamente.

### 3. Testar

Mande `/start` para o bot:
https://t.me/PereiraBarbershop_bot

Você deve receber uma resposta instantânea!

## Como os barbeiros usam

### Para configurar Telegram

1. Barbeiro abre o bot: https://t.me/PereiraBarbershop_bot
2. Envia `/start`
3. Bot responde INSTANTANEAMENTE com o Chat ID
4. Barbeiro copia o ID
5. Admin configura no painel admin

### Para ver agendamentos do dia

1. Barbeiro abre o bot
2. Envia `/hoje`
3. Bot responde com todos os agendamentos de hoje

## Arquitetura

```
Telegram
   ↓ (webhook)
Vercel Serverless Function (/api/telegram)
   ↓
Supabase (buscar agendamentos)
   ↓
Telegram (responder)
```

## Como funciona a notificação de agendamento

Quando um cliente agenda pelo site (`agendar.js`):

1. Agendamento é salvo no Supabase
2. O código busca o Chat ID do barbeiro
3. Envia notificação via API do Telegram
4. Barbeiro recebe instantaneamente

Isso **JÁ FUNCIONA** e não depende do webhook ser configurado!

## Troubleshooting

### Bot não responde

Verifique se o webhook está configurado:

```bash
curl -s "https://api.telegram.org/bot8932305524:AAE4CBvVQb-lMG4lnE57WVRKr7Pdwteewds/getWebhookInfo" | jq
```

A `url` deve ser: `https://pereira-barbershop.vercel.app/api/telegram`

Se não estiver, rode novamente:

```bash
bash scripts/configurar_webhook.sh
```

### Deploy não funciona

Verifique o Vercel dashboard:
https://vercel.com/pantojinho/pereira-barbershop

Procure por erros nos logs.

### Agendamentos de hoje não aparecem

Verifique se o Chat ID está configurado corretamente no Supabase:

```sql
SELECT id, name, telegram_chat_id FROM barbers;
```

## Atualizar o webhook

Se você mudar a URL ou o código, pode reconfigurar:

```bash
bash scripts/configurar_webhook.sh
```

## Remover webhook (voltar para manual)

Se quiser desativar o modo automático:

```bash
curl -s -X POST "https://api.telegram.org/bot8932305524:AAE4CBvVQb-lMG4lnE57WVRKr7Pdwteewds/deleteWebhook"
```
